# 🌿 المخطط التأسيسي والاستراتيجي لمنصة "بيّضها" (Project Blueprint)
**رؤية هندسية واجتماعية للارتقاء بالبيئة الحضرية لمدينة البيض عبر التكنولوجيا المدنية والتضامن التشاركي**

---

## 1. الفلسفة المجتمعية ومنهجية التبني الميداني (Civic Adoption)

### 💡 من "تطبيق شكاوى" إلى "منصة فخر وتويزة رقمية"
أثبتت التجارب الدولية في تطبيقات التكنولوجيا المدنية (Civic Tech) أن التطبيقات التي تقتصر على تقديم "الشكاوى والتذمر" تواجه مقاومة من السلطات المحلية وفتوراً سريعاً من المواطنين.
تعتمد منصة **"بيّضها"** نموذج **"التويزة الرقمية" (Digital Touiza)** القائم على:
1. **العمل الميداني الإيجابي المشترك:** لا نكتفي برصد المشكلة بل نوفر فوراً أداة لتنظيم حملة تطوعية لمعالجتها.
2. **سجل الفخر والإنجاز (Wall of Impact):** توثيق تحول الأماكن (قبل / بعد) وذكر أسماء الجمعيات والأحياء ومصالح البلدية المساهمة لتعزيز روح المنافسة الإيجابية بين الأحياء.
3. **تخفيف العبء عن المصالح البلدية:** توفير بيانات لوجستية دقيقة (حجم التدخل، مسلك الشاحنات، نوع النفايات) مما يوفر على البلدية الجهد والوقود في المعاينة الأولية.

## 2. مصفوفة الشراكة والتنسيق المؤسساتي (Institutional Framework)

| الهيئة / الشريك | الدور الميداني في المنصة | القيمة المضافة المتبادلة |
| :--- | :--- | :--- |
| **المجلس الشعبي البلدي (APC البيض)** | توفير شاحنات الرفع والعتاد الثقيل ونقل النفايات إلى مركز الردم التقني (CET). | الحصول على خارطة حرارية دقيقة للنقاط السوداء واحتياجات الأحياء اللوجستية. |
| **محافظة الغابات لولاية البيض** | توفير شتلات الأشجار السهبية الملائمة (صنوبر حلبي، بطم) والإشراف التقني على الغرس. | رفع نسب نجاح حملات التشجير وحمايتها وتوسيع الحزام الأخضر للمدينة. |
| **مديرية الحماية المدنية** | تأطير السلامة الميدانية وتنقية مجاري الأودية ونقاط تجمع المياه قبل موسم الأمطار. | الوقاية الاستباقية من مخاطر الفيضانات وانسداد قنوات صرف مياه الأمطار. |
| **مصالح الأمن والدرك الوطني** | تأمين مسالك الحملات التطوعية وتنظيم لقاءات تحسيسية للوقاية من الآفات الاجتماعية. | تعزيز الأمن الجواري والترابط المجتمعي الإيجابي مع شباب الأحياء. |
| **جمعيات المجتمع المدني ولجان الأحياء** | حشد المتطوعين، قيادة حملات التنظيف، والمتابعة الدورية لنظافة الأحياء. | منصة موحدة لنشر نشاطاتهم وتوثيق إنجازاتهم واستقطاب المتطوعين. |

## 3. المعمارية التقنية الصفرية (100% Zero-Cost Architecture)

تم تصميم المنصة لتشتغل مدى الحياة بميزانية **0 DZD / 0 USD**، لتجنب أي توقف ناتج عن تكاليف الاشتراكات:

```
[ Frontend: HTML5 / CSS3 / Vanilla JS PWA ] 
              │
              ├──► [ Maps: Leaflet.js + OpenStreetMap (مجاني 100%) ]
              │
              ├──► [ Hosting: Vercel / Cloudflare Pages (Free Tier) ]
              │
              └──► [ Backend & DB: Supabase PostgreSQL + PostGIS (Free Tier) ]
```

1. **الخرائط:** Leaflet.js مفتوح المصدر بالكامل، لا يتطلب أي مفتاح API تجاري ولا يفرض رسوماً على عدد الزيارات.
2. **ضغط الصور التلقائي قبل الرفع (Client-Side Compression):** تحجيم الصور في متصفح المواطن إلى أقصى حجم (150KB) قبل إرسالها لضمان استهلاك الحد الأدنى من التخزين المجاني.
3. **منع التكرار (Proximity Check):** حجب رفع صور مكررة في محيط 85 متراً وتحويل العملية إلى تصويت وتأكيد تشاركي (+1).
4. **تطبيق ويب تقدمي (PWA):** يعمل كتطبيق هاتف ذكي مباشر بدون رسوم اشتراك مطوري Google Play أو Apple App Store.
