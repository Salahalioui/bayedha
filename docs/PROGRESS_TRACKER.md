## 📋 سجل المهام التفصيلي

### ✅ المرحلة 1: واجهة المواطن والمنسق الميداني الموحد (Completed)
- [x] **تأسيس نظام التصميم السهبي (Steppe & Pine Design System):**
  - ألوان طبيعية مستوحاة من البيض: الأخضر الصنوبري (`#1b362d`) والترابي السهبي (`#b55a22`).
  - خط `Readex Pro` للعربية و `Plus Jakarta Sans` للفرنسية.
  - أيقونات SVG خطية خفيفة بدون مكتبات ثقيلة.
- [x] **الخارطة التفاعلية الحية (Leaflet Engine):**
  - شارات مخصصة للنقاط السوداء، المبادرات، والفضاءات المؤهلة.
  - استعراض مواقع أحياء البيض: حي المصالحة، وادي الفحم، حي السلام، الحرم الجامعي، وغيرها.
- [x] **نظام استمارة البلاغ المهيكل:**
  - كتابة يدوية لاسم الحي لمرونة التسميات المحلية.
  - تحديد دقيق للحجم ونوع العتاد (يدوي / شاحنة 3.5T / جرافة ثقيلة).
- [x] **محرك منع التكرار (Proximity & Upvoting Engine):**
  - معادلة Haversine الدقيقة لحساب المسافة بالمتر.
  - تنبيه فوري إذا كان هناك بلاغ على بعد أقل من 85 متراً.
  - زر تأكيد البلاغ القائم دون إرفاق صور جديدة للحفاظ على الخطة المجانية.
- [x] **بوابة المنسق الميداني الموحد (Single Coordinator Portal):**
  - ولوج آمن عبر رمز سري (PIN: `2026`).
  - لوحة فرز لحذف البلاغات الوهمية (Spam).
  - أداة إغلاق البلاغ وتوثيق الوضع النهائي بصورة "بعد" والنشر التلقائي في سجل الإنجازات.
  - مولد تقارير المتابعة اليومية للبلدية الجاهز للنسخ والإرسال عبر WhatsApp / SMS بنقرة واحدة.
- [x] **إنشاء مستودع GitHub ومزامنة الكود والتوثيق:**
