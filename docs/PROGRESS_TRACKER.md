## 📝 سجل التعديلات التفصيلي (Changelog)

### الإصدار v1.6.0 (17 أوت 2026) - تحسينات الوصولية (WCAG 2.2 AA)، الأمان، وتكامل المبادرات على الخارطة:
* **تكامل المبادرات التطوعية مع الخارطة التفاعلية (Campaigns Map Unification):**
  - تصحيح جلب ومطابقة خطوط الطول والعرض (`latitude`, `longitude`) للمبادرات المسجلة في السحابة.
  - دمج المبادرات تلقائياً داخل دالة `getAllSpots()` و `getFilteredSpots()` لتظهر بالونات المبادرات باللون البرتقالي التحذيري على الخارطة مع إمكانية الانضمام المباشر.
* **عزل الصلاحيات الإدارية وبرمجة المبادرات (Coordinator Authorization):**
  - تقييد زر "برمجة مبادرة تطوعية" ليتطلب إدخال الرمز السري للمنسق (`isCoordAuthenticated`) لمنع إدراج مبادرات عشوائية من طرف العموم دون اعتماد رسمي.
  - إضافة تبويب رابع داخل بوابة المنسق الميداني: `4. برمجة مبادرة جديدة`.
* **الوصولية الشاملة ومعايير WCAG 2.2 AA:**
  - تفعيل حصر الفوكس (Focus Trap) داخل النوافذ المنبثقة ومنع تسرب الفوكس للخلفية مع استعادة التركيز للزر الأصلي عند الإغلاق.
  - إتاحة التنقل بين بطاقات الحجم والمسالك باستخدام مفاتيح الأسهم و `Space / Enter`.
  - إضافة حلقات تركيز عالية التباين `:focus-visible` ومراعاة تقليل الحركة للمستخدمين ذوي الحساسية البصرية.
* **الأمان وسد ثغرات الحقن (Stored XSS Protection):**
  - تعقيم شامل لكافة نصوص البلاغات والمبادرات وأسماء الجمعيات عبر دالة `escapeHTML()`.
* **إنشاء سكربت الإعداد السحابي الشامل (`docs/supabase_setup.sql`):**
  - توفير ملف SQL كامل يشمل الجداول، PostGIS، سياسات RLS العامة، وقنوات النشر اللحظي (Realtime).
